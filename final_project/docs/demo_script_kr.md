# Upbit MCP 과제 시연 대본

## 1. 소개

이번 기말고사 과제로 Upbit 데이터를 조회할 수 있는 MCP 기반 프로그램을 구현했습니다. MCP 서버는 Upbit 공개 시세 API에서 코인 가격, 호가창, 마켓 정보, 캔들 데이터를 가져오고, MCP 클라이언트는 서버에 연결해 해당 도구들을 호출하는 구조입니다.

## 2. 구조 설명

전체 구조는 클라이언트, MCP 서버, Upbit API 세 부분으로 나뉩니다. 클라이언트는 서버를 stdio 방식으로 실행하고 MCP 세션을 초기화합니다. 서버는 `FastMCP`를 사용해 여러 tool을 등록해 두었고, 클라이언트는 `list_tools()`로 tool 목록을 확인한 다음 `call_tool()`로 원하는 데이터를 요청합니다.

## 3. 실행 시연

먼저 다음 명령어로 전체 데모를 실행합니다.

```bash
python clients/upbit_mcp_client.py demo
```

이 명령을 실행하면 MCP 클라이언트가 서버를 실행하고, 서버가 제공하는 tool 목록을 출력합니다. 이후 비트코인과 이더리움 현재가, 비트코인 호가창, 최근 분봉 데이터를 순서대로 조회합니다.

## 4. 핵심 기능 설명

현재가 조회는 `get_ticker` tool을 사용했습니다. 이 tool은 현재가, 전일 종가, 24시간 변동률, 24시간 누적 거래대금을 보여줍니다.

호가창 조회는 `get_orderbook` tool을 사용했습니다. 매도호가와 매수호가를 단계별로 출력해서 현재 주문장 상태를 확인할 수 있습니다.

마켓 정보 조회는 `get_market_detail`과 `list_krw_markets`를 사용했습니다. 이를 통해 업비트 원화마켓에 어떤 코인이 있는지, 특정 코인이 유의 종목인지 확인할 수 있습니다.

## 5. 마무리

이 프로그램은 단순히 API를 직접 호출하는 코드가 아니라, MCP 서버가 외부 데이터를 tool 형태로 제공하고 MCP 클라이언트가 그 tool을 발견하고 호출한다는 점이 핵심입니다. 따라서 과제 요구사항인 MCP 서버와 MCP 클라이언트 기반 Upbit 데이터 조회 구조를 만족합니다.
